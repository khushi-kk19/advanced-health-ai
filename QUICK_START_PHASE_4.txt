═══════════════════════════════════════════════════════════════════════════════
                    WHAT EACH SCRIPT DOES
═══════════════════════════════════════════════════════════════════════════════

train_stress_phase123.py
  Trains 3 phases of models
  --phase 1        : Train LSTM only
  --phase 2        : Train CNN only
  --phase 3        : Train Hybrid (BEST)
  --phase-start    : Skip to specific phase
  --sample-fraction: Use % of data (0.1 = 10%)
  --epochs         : Training epochs

inference_stress_phase123.py
  Make predictions on new data
  --model lstm     : Use LSTM model
  --model cnn      : Use CNN model
  --model hybrid   : Use Hybrid model
  --checkpoint     : Path to saved model

evaluate_stress_models.py
  Calculate performance metrics
  --model lstm     : Evaluate LSTM
  --model cnn      : Evaluate CNN
  --sample-fraction: % of test data
